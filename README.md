# Pandas EDA Practice

**A structured practice repository for mastering Pandas** — the primary library for data manipulation and Exploratory Data Analysis (EDA) in Python.

---

## Overview

This repository guides a learner from core Pandas concepts to practical data cleaning and analysis techniques through carefully sequenced Jupyter notebooks.

The goal is to develop the exact skills required for:
- Real-world data preprocessing
- Machine Learning feature preparation
- Analytical thinking with tabular data

Emphasis is placed on **clarity, systematic progression, and independent practice**.

---

## Learning Objectives

By completing this repository, a learner will be able to:

- Create and manipulate Pandas Series and DataFrames confidently
- Load, inspect, and understand tabular data from CSV files
- Perform precise row and column selection using `loc` and `iloc`
- Filter datasets based on multiple conditions
- Detect and handle missing values effectively
- Apply basic cleaning and transformation techniques
- Perform GroupBy operations and meaningful aggregations
